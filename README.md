# 菄家｜奇幻寫作學院

以**學校作文能力**為基礎，逐步培養自由創作與獨立寫作的 12 週互動課程。

## 課程方向
- **第一優先**：讓學生的學校作文寫得更好。
- **進階目標**：能自由創作自己的故事。
- **書寫安排**：由短句與短段循序增加至完整文章。
- **任務模式**：每週獨立任務，搭配共同奇幻世界觀。
- **期末成果**：學生獨立構思、寫作、檢查與修改。
