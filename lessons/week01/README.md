# 第一週｜寫作入學試煉

**課程定位：**以觀察與完整句為核心，讓學生用短句清楚表達一件事物。

**本週目標：**
- 能說出物品至少三個可觀察特徵。
- 能把口語描述整理成 3–5 個完整句。
- 能選出一句加入具體細節。
- 能依檢查表修正基本標點與語意。

## 建議任務
請學生在奇幻寫作學院的入學日，觀察一件「神祕入學物品」。先口述，再用 3–5 句寫下它的外形、顏色、特徵及可能用途。可由老師示範一組普通句與具體句的比較。

## 最簡單的檢查表
- [ ] 我寫清楚這是什麼。
- [ ] 我有描述至少三個特徵。
- [ ] 每句都有完整意思。
- [ ] 句尾有適當標點。
- [ ] 我自己讀過並修改一次。
